A Python desktop application that adds customizable watermarks to your images. Built with Tkinter for the GUI and Pillow for image processing — simple, fast, and no command-line required.

---Features-----
Load images — Supports JPG, PNG, BMP, GIF, and WebP

Custom text watermarks — Type any text you want

Color picker — Choose watermark color with a built-in color chooser

Position control — Place watermark at any of 9 positions (corners, edges, center)

Opacity slider — Adjust transparency from 10% to 100%

Font size control — Scale the watermark text to fit your image

Live preview — See the result before saving

Save output — Export to your chosen location and format

Non-destructive — Original image is never modified
